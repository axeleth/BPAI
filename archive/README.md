# Archive

This folder holds material the thesis builds on or was used for preparation. None of it is thesis output; the thesis code is in [`../thesis/`](../thesis/).

- `baseline-group6/`: graph-based CBS solution for the TU Delft AE4422-20 ABMS assignment by **Florina Sirghi and Vincent van Gorp** (group 6, 2021/22). It is the CBS baseline that the thesis extends with speed deviations. It includes their own simulation data.
- `mapf-tutorial/`: the grid-world MAPF warm-up exercise (independent, prioritized and CBS planners), its reference answers, and the tutorial slides and PDFs.
- `CAM_DS_EP_STOMPA.ipynb`: an unrelated Colab notebook.
